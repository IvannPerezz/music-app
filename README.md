# BitChord Desktop

A port of the BitChord apk to a desktop version using Electron (plenty of new features that the app doesn´t have)

Port para Windows de [BitChord](https://github.com/kushagrasinghx/BitChord), un cliente de YouTube Music, hecho con Electron.

## Empezar

1. Instala [Node.js](https://nodejs.org) (versión 22 o superior).
2. En esta carpeta: `npm install`
3. `npm run mock` para abrir BitChord con datos de prueba, o `npm start` para usarlo con YouTube Music.

`npm run deploy` empaqueta la versión actual y la deja lista en tu BitChord instalado: se aplica al cerrarlo y volver a abrirlo.

El historial de versiones está en `CAMBIOS.txt` y la guía técnica para Claude Code en `CLAUDE.md`.
